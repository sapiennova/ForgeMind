# Predictive Maintenance & Manufacturing Forecasting

This repo contains two ML projects developed during an industrial internship with UCT:
- Project 6: Predicting Remaining Useful Life (RUL) of Turbofan Engines
- Project 11: Predicting Output in a Multi-Stage Continuous Manufacturing Process

## Project 6 - RUL Prediction
- Dataset: NASA CMAPSS FD001
- Model: LSTM using TensorFlow/Keras

## Project 11 - Output Forecasting
- Model: XGBoost & Random Forest
- Dataset: Simulated high-frequency manufacturing process

## Setup
```bash
pip install -r requirements.txt
```

## Execution
```bash
python project_6_rul_prediction/rul_lstm_model.py
python project_11_manufacturing_output/output_forecast_xgboost.py
```
